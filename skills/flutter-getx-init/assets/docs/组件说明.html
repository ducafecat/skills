入口与使用约定

页面、main.dart、global.dart 使用公共总入口；common 内跨子目录使用目标 index.dart，同目录直接导入功能文件。

// 页面使用
import 'package:{{package_name}}/common/index.dart';

// common/components 内使用
import '../widgets/index.dart';

// common/widgets 内部使用
import 'button.dart';

以上是不同文件位置的导入示例，不在同一文件中同时引入。页面还需按使用情况导入 Flutter Material。使用片段中的 controller、回调、状态和 key 由页面提供；示例中文用于说明，正式业务文案使用 TrKeys。

样式复用 AppStyle、AppTextStyles、AppRadius 与 AppSpacing；新增组件按功能归入现有文件，并维护 widgets/index.dart。表单通过 form/index.dart 导出。接口参考展示本次生成时的源码签名，代码变更后需同步更新本说明。

01 / 交互

按钮

lib/common/widgets/button.dart ↗

通用按钮、项目主次按钮、玻璃图标按钮和顶部动作集中维护。

ButtonWidgetVariantButtonWidgetAppButtonVariantAppButtonSizeAppButtonPrimaryButtonGhostButtonGlassIconButtonTopBarAction
  • ButtonWidget 支持 primary、secondary、destructive、outline、ghost、link、icon；文案为 text，回调为 onTap，icon 接受 Widget。
  • AppButton 使用 label / onPressed，icon 接受 IconData，默认 expanded=true。PrimaryButton 和 GhostButton 复用 AppButton。
  • 加载时两类按钮都禁止重复点击。AppButton 隐藏文案绘制但保留布局；ButtonWidget 在内容旁追加加载指示器。
  • GlassIconButton 默认视觉尺寸 32，触控区域至少 48；semanticLabel 必填。TopBarAction 的基准视觉高度为 32，支持大字自适应。

// 示例中的回调与状态由所在页面提供。
PrimaryButton(
  label: '保存',
  loading: saving,
  onPressed: onSave,
)

  '筛选',
  icon: const Icon(Icons.filter_list),

文字

lib/common/widgets/text.dart ↗

沿用 AppTextStyles 的文字组件，支持系统字号缩放。

TextWidgetTypeTextWidget
  • h1 → display；h2 → pageTitle；h3 → sectionTitle；h4 → cardTitle；body → body；label → label；muted → secondary。
  • 先应用项目排版与 weight，再合并 textStyle，最后应用显式 color、size 和 fontStyle。textStyle 中的字重可覆盖 weight。
  • 缩放档位：small 为 0.8，medium 为 1，large 为 1.3；未指定 scale 不额外缩放。
DART · 使用片段
const TextWidget.h4('订阅频道')

const TextWidget.body(
  '最新更新内容',
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
)

图片与 SVG

lib/common/widgets/image.dart ↗

本地资源、普通网络图片和 SVG 的基础显示能力。

ImageWidgetTypeImageWidget
  • ImageWidget.img 自动区分资源路径与 http/https 地址；以 // 开头的网络地址补齐 https。普通网络图片使用 CachedNetworkImage。
  • ImageWidget.svg 支持资源与网络地址；svgRaw 接收 SVG 源码，均使用 flutter_svg。
  • 支持 width / height、fit、radius、color、placeholder、errorWidget 和 elevation。错误占位保留指定尺寸。
  • 业务视频封面与频道头像使用 common/components 的 ProxyImage / ProxyAvatar；ImageWidget 不提供业务鉴权、会话隔离和后端代理。
DART · 使用片段

  '<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24">'
  '<circle cx="12" cy="12" r="10" fill="currentColor"/></svg>',
  width: 24,
  height: 24,
  radius: 0,
)

头像

lib/common/widgets/avatar.dart ↗

图片、SVG、首字符头像与文字兜底头像。

AvatarWidgetTypeAvatarWidgetAppAvatar
  • AvatarWidget.img / svg 接受路径；text 取去除首尾空白后的首个 Unicode 字符簇并转为大写。空文字显示 ?。
  • AvatarWidget 始终圆形裁切，默认尺寸为 48；图片地址为空或加载失败显示文字兜底。
  • AppAvatar 默认尺寸 40，直接显示传入的完整 text，可指定 background / foreground。业务频道头像使用 ProxyAvatar。

输入与搜索

lib/common/widgets/input.dart ↗

基础输入、带说明的输入框和搜索输入集中维护。

InputWidgetAppFormFieldGlassSearchField
  • InputWidget 支持清空、密码显隐、只读、前后缀、输入法类型和自动焦点；只读时不显示清空按钮。
  • 组件只释放内部创建的控制器；外部 controller 由调用方释放。替换外部 controller 后同步显示新内容。
  • AppFormField 的 label / helper / errorText 用于展示，不参与 Form 的自动校验；GlassSearchField 额外支持 onSubmitted。
DART · 使用片段
InputWidget(

lib/common/widgets/scaffold.dart ↗

统一背景、安全区、内容留白和页脚。

PageScaffold
  • PageScaffold 必填 body，支持 topBar、footer、padding、scrollable、safeAreaTop / safeAreaBottom。
  • 默认正文有水平页面留白；fullBleed=true 去掉默认留白，显式 padding 始终优先。
  • 内容自行拥有列表滚动时保持 scrollable=false；组件在可用高度很小时处理页脚可达性。
DART · 使用片段

  topBar: TopBar(title: '订阅'),
  body: const TextWidget.body('订阅内容'),
)

尺寸档位

lib/common/widgets/widget_scale.dart ↗

基础组件共享的尺寸枚举。

WidgetScale
  • WidgetScale.small / medium / large 供 ButtonWidget、TextWidget 使用。
  • ButtonWidget 缩放字体和内边距；TextWidget 缩放字号。该枚举不会替代 Flutter 系统文字缩放。
DART · 使用片段
const TextWidget.body(
  '辅助说明',
  scale: WidgetScale.small,
)
