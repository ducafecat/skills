# 产品契约检查

只检查最终用户、运营/管理员或外部集成能够观察到，且可由 diff 与仓库代码验证的契约；不查找外部需求 Spec。

## 检查范围

- 创建、更新、删除、关闭、恢复、过期及异步完成等生命周期和状态转换。
- 角色可见范围、前后台差异、导出、通知和外部同步中的权限一致性。
- 输入校验、默认值、空值、枚举、错误码、错误文案、空态、部分失败和恢复路径。
- 金额、时间、时区、排序键、归因、负责人、附件和链接等字段的端到端保真。
- 旧数据、旧客户端、旧载荷、字段重命名和配置迁移的兼容行为。
- 重复提交、回调重放、重试及异步恢复的幂等性。
- API、UI、通知、报表、导出与外部系统之间的状态和字段一致性。
- 列表筛选、排序、分页、计数与导出是否基于同一选择集并保持稳定顺序。
- 模板变量的传入、命名、默认值、转义和最终渲染是否完整。

## 成立条件

- 说明被破坏的既有契约，以及字段或状态从变更代码流向可观察结果的路径。
- 指明受影响角色、接口或外部系统和实际错误结果。
- 删除契约保护时，必须验证最终状态确实缺失且没有替代实现。

## 不报告

- 只能依赖未提供需求、设计稿或产品偏好才能判断的问题。
- 纯内部重构且所有可观察输入输出保持一致的变化。
- 没有端到端数据流证据的字段遗漏或状态推测。
