# DevOps 检查

## 检查范围

- CI/CD 条件、步骤顺序、缓存、制品和失败传播是否正确。
- Docker、部署脚本、启动命令、健康检查及回滚路径是否可执行。
- 环境变量、默认配置和不同环境之间是否存在不兼容或危险回退。
- 依赖声明与锁文件是否一致，构建是否可复现。
- 日志、指标、告警和错误输出是否足以定位实际运行故障且不泄露敏感数据。
- 声称支持的平台上，路径、shell、权限和命令是否兼容。

## 成立条件

- 指明实际会运行的目标环境、触发步骤和失败结果。
- 跨平台问题只在仓库确实支持相应平台时成立。

## 不报告

- 仓库没有采用的部署平台、CI 服务或运维流程。
- 纯格式、注释、一般代码逻辑或未经证实的最佳实践偏好。
- 仅缺少可选监控但不影响本次变更可诊断性的建议。
