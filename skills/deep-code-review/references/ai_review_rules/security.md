# 安全检查

## 检查范围

- SQL、命令、HTML、模板、路径或其他解释器边界上的注入与逃逸。
- 身份认证、对象级授权、角色权限和租户隔离是否可被绕过。
- 凭证、密钥、令牌、敏感字段是否被硬编码、记录、返回或发送到错误边界。
- 不可信输入的校验、规范化以及输出到相应上下文时的编码。
- 文件路径、上传下载、重定向、回调地址和服务端请求的边界控制。
- 加密算法、随机数、签名验证和密钥使用是否破坏安全属性。

## 成立条件

- 指明攻击者可控数据如何到达敏感操作，以及缺失或失效的控制。
- 指明成功利用后的权限、数据或系统影响；只有理论危险而没有可达路径时不报告。

## 不报告

- 仅凭变量名猜测存在秘密或敏感数据。
- 没有仓库证据支持的部署假设、依赖漏洞版本或外部服务行为。
- 普通输入错误但不存在安全边界影响的问题。
