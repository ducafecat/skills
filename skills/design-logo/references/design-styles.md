# 设计风格选项目录

询问风格时展示下列全部分组与选项，不提前按行业筛掉风格。风格持续演化，没有封闭的“全部风格”；本目录覆盖常见方向，始终允许补充、自定义、混搭，也可给参考图。分类存在交叉，不应作为互斥规则。

**0. 无限制自由发挥（默认）**：由设计师跨风格探索，不预设平面、几何、科技感或低饱和。

| 分组 | 可选风格（可单选、多选或混搭） |
| --- | --- |
| 简约与几何 | 极简主义、平面设计、几何抽象、负空间、线性／单线、模块化／网格、瑞士国际主义、包豪斯、现代主义 |
| 文字与书写 | 纯字标、首字母／字母组合、定制字体、衬线经典、无衬线现代、手写签名、书法／毛笔、中文字体设计、篆刻／印章、实验排版 |
| 具象与角色 | 具象符号、动物／植物、人物肖像、吉祥物、卡通、Q 版、漫画、插画叙事、剪影、图腾 |
| 手作与自然 | 手绘涂鸦、素描／速写、版画／木刻、水彩／水墨表现、有机流体、仿生、自然生态、剪纸／拼贴、民艺／民族纹样 |
| 经典与复古 | 传统徽章／盾徽、纹章、复古招牌、美式复古、Art Deco 装饰艺术、Art Nouveau 新艺术、维多利亚装饰、怀旧印刷、蒸汽朋克 |
| 立体与材质 | 3D 立体、等距视角、浮雕／压印、拟物、黏土／软胶、折纸／折面、玻璃／透明、金属／镀铬、液态金属、全息／虹彩、陶瓷／木材／纸张质感 |
| 光色与数字 | 多色渐变、网格渐变、霓虹／发光、赛博朋克、未来科技、Y2K、像素／8-bit、故障艺术、数字点阵、线框／参数化 |
| 艺术与实验 | 波普艺术、孟菲斯、迷幻、超现实、极繁主义、粗野主义／新粗野主义、解构主义、抽象表现、欧普／视觉错觉、动态／生成式视觉语言 |
| 气质与文化 | 奢华精致、亲和可爱、童趣、运动动势、硬核工业、东方禅意、国潮、北欧简约、地中海／地域文化 |

气质、结构和技法可交叉，例如“手写字标 + 金属材质”或“动物吉祥物 + 复古徽章”。用户也可直接输入列表之外的风格。动态／生成式方向在本技能中交付代表性的静态 SVG；真实动画或位图材质需单独明确交付范围，不能虚报能力。水彩、发光等在当前 SVG 白名单内以路径、渐变和叠层近似表达，说明表现取舍。
