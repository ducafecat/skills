# 品牌 Logo 视觉规范与验收

## 设计依据

所有偏好默认「无限制自由发挥」，以用户明确选择与品牌需求建立设计语言。风格选项见 [design-styles.md](design-styles.md)。不预设科技、几何、平面、低饱和、无文字或无衬线字体，不以风格本身作为淘汰理由。

## 造型、配色与字体

- 造型可抽象、具象、字标、角色、徽章或混合；不要把现成 UI 图标直接当作品牌资产。
- 允许单色、多色、渐变、3D、玻璃、金属、霓虹等；根据场景控制细节、对比和辨识度。
- 六稿不能只换颜色；自由发挥时覆盖至少四种视觉家族，明确选择单一风格时在该风格内变化。
- 字体可衬线、无衬线、手写、书法或定制字形。核查实际字体许可；用于画廊的文字转为可编辑轮廓，保留正确拼写。
- 在 16 / 32 / 48 / 128 / 512px 预览；小尺寸必要时另画简化版，说明与主稿关系。主稿与单色适配版分别验收。
- SVG 使用构建脚本允许的路径、形状、渐变、蒙版与叠层。复杂材质可近似表达并说明取舍，不能嵌入位图或引入外链绕过校验。

## 六稿验收（每项 1–5 分）

| 项目 | 目标 |
| --- | --- |
| 表达质量 | 细节服务于风格和品牌含义 |
| 辨识度 | 48px 可看清主形 |
| 风格契合 | 符合用户选择；自由发挥时探索充分 |
| 视觉一致 | 构图、字形、材质表达协调 |
| 品牌语义 | 与产品定位有可解释的联系 |
| 独特性 | 与常见 UI 图标或既有商标有明显差异 |
| 延展性 | 深浅底、单色和小尺寸有合适适配 |
| 原创处理与授权 | 来源、字体许可和实际修改可追溯 |

低于 32/40 分先内部修改再展示；评分不构成商标注册或法律结论。

## 案例研究与原创性

- 案例只研究方法，不描摹、镜像或微调已有商标，不用现成 SVG 换色冒充原创。
- 逐稿列出案例参考、借鉴方法与禁止复制的特征；参考 SVG 列出原图与许可证。
- 研究覆盖所选风格；自由发挥时跨风格研究，不能只检索几何科技案例。
